# Naqsh store (Next.js)
npm install, then npm run dev, then open http://localhost:3000
Pages: / (home with Men/Women toggle), /shop (category pages with the runway view), /shop (filters), /brands, /product/[slug], /cart (cash on delivery checkout), /about.
Edit brands, categories and prices in app/catalog.js, the runway lives in app/Runway.js.
Garments are SVG placeholders (app/Garment.js): replace with real photos later.
Orders are not saved anywhere yet: connect WhatsApp, email or a database before going live.
